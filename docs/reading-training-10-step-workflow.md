# 阅读训练十步流程

本文件是当前课程的用户与实现说明。开发验收以[完善开发计划](./reading-training-improvement-plan.md)和[执行 TODO](./reading-training-improvement-todo.md)为准；旧八轮记录只读，不按新版步骤重新解释。

## 总流程

```text
预读外部线索 → 全文快速浏览 → 重要段落三句法 → 全文三点总结
→ 5W1H 提问 → 隐藏假设与证据风险 → 简化图尔敏
→ 完整图尔敏 → 费曼解释 → 全文复盘
```

第一步只要求完成标题、作者、来源、首段、末段以及小标题、图表和强调信息的预读，不要求用户先读完整篇文章。每一步有固定主任务；AI 追问只显示在反馈中，不能替换主任务。

## 十步任务

### 1. 预读 `preview`

查看标题、副标题、作者、来源、日期、第一段、最后一段、小标题、图表和强调内容。记录观察、预计文章要回答的问题以及目前未知的内容。

完成条件：核对元信息状态，填写首末段观察、小标题、图表和强调信息显示的内容、预计问题和未知内容。提取失败不等于原文没有提供；可区分“已找到”“提取未获得”和“已核实原文未提供”。

### 2. 第一遍快速浏览 `quick-browse`

快速通读全文，记录整体结构、每段功能标签和具有代表性的首句或末句。段落标签可使用背景、现象、数据、原因、例子、对比、转折、解释、结论、建议、限制和暂不确定。

完成条件：有结构概述，并为正文或引用段落标记功能或暂不确定。此步骤不要求逐句分析，也不把一个例子扩大为全文结论。

### 3. 重要段落三句法 `three-sentence`

从第二步的候选中选择重要段落，也可以增删选择。对每个所选段落记录：

1. 这段说了什么？
2. 为什么这么说？没有原文依据时写“原文未提供”。
3. 这段想告诉我什么？
4. 这段在全文中的作用是什么？
5. 原文依据是什么，并注明是明示、推断还是未交代。

完成条件：至少选择一段，且仅所选段落需要完成这些记录；不强迫分析全文所有段落。

### 4. 全文三点总结 `three-points`

用三个短要点覆盖全文的现象或问题、原因/证据/展开以及趋势/结论/限制。每点都填写对应的原文依据，并检查是否重复、遗漏、把个案扩大或加入外部知识。

中文、日文和韩文按最多 15 个非空白可见字符计数；英文按最多 15 个空白分隔词计数。前后台使用同一规则。

完成条件：正好三个要点，每点通过长度校验并有依据关联。

### 5. 5W1H 提问 `questions`

从 Who、What、Why、How、When、Where 中选择问题类别，提出一个或多个问题，再选出 1–2 个关键问题。每个关键问题记录重要性、相关段落、原文已经回答的内容和原文没有回答的内容。

完成条件：至少一个关键问题；不要求六类全部出现。“原文没有回答”是阅读边界记录，不能代替个人问题或重要性说明。

### 6. 隐藏假设与证据风险 `assumptions`

围绕一个检查对象区分：原文明确说明了什么、作者默认了什么、前提不成立会造成什么影响、可能的其他解释、证据不足和仍不确定的问题。分别标记明示、上下文推断、未交代和推理风险。

“原文没有说明”不等于“作者说错了”。非论说文可以有依据地记录“未发现可拆解论证”，不能强迫编造因果或反驳。

### 7. 简化图尔敏 `toulmin-simple`

选择一条核心论证并确认唯一的 argument ID，记录主张 Claim、证据 Data/Grounds 和保证 Warrant（证据为什么能支持主张）。每项注明原文明示、上下文推断或原文未交代；推断要写理由。证据是材料，保证是连接规则，二者不能互相冒充。

### 8. 完整图尔敏 `toulmin-full`

只读展示第七步同一 argument ID 的主张、证据和保证，再补充支撑 Backing、限定 Qualifier、反驳 Rebuttal、最薄弱环节和最需要核实的地方。反驳要区分原文回应与读者提出；原文未回应时如实记录。

修改第七步论证后，第八步保留旧内容并标记待复核，不能静默沿用或继续使用旧版本作为新答案。

### 9. 费曼解释 `feynman-review`

选择一个核心概念或论证，用自己的话向十二岁的孩子解释，包含通俗解释、因果过程、例子和适用边界。例子必须标记为“原文案例”或“自创类比”；自创类比用于帮助理解，不能当作原文证据。

### 10. 全文复盘 `final-review`

系统汇集前面已经完成的主旨、三点、核心论证、前提、最强证据、薄弱点、不确定性和需要重读的位置。用户负责核对、修改和补充个人判断，不要求机械重抄已有答案。

完成条件：所有待复核项都有处理记录；未评分不阻止本地完成，保存失败或必填结构缺失才阻止推进。巩固练习独立存储，不覆盖第十步，也不增加正式完成数。

## 保存、回看与修订

- 自动保存只更新当前步骤草稿，不为每次按键创建版本。
- 保存请求携带 session ID、step ID 和草稿修订号；过期写入被拒绝，当前输入保留。
- 明确提交或“保存并继续”前冻结答案版本；评分、反馈、参考答案和导出都绑定该版本。
- 回看是只读视图，不改变当前步骤、完成状态或当前草稿。
- 点击“编辑此回合”才进入编辑；系统创建新版本，保留旧答案和旧反馈，并将受影响的后续步骤标为待复核。
- “重新开始”创建新的正式会话并归档旧会话；历史会话可查看和导出。
- 测试会话使用独立存储，直达步骤不计入正式成长统计。
- AI 未配置、连接失败或模型格式错误时，本地已保存答案仍可继续；AI 结果失败不删除答案。

## 原文与依据

训练会话保存文章快照。正文、标题、列表、图表文字、图片替代文本和强调信息均可作为来源块；来源块使用稳定 ID。引用必须是对应来源中的连续短文本，正文段落编号与来源块 ID 同时保留。文章变化后创建新快照，不让旧引用自动指向新文章。

## 导出与统计

Markdown、JSON 和 PDF 应标记课程版本、会话、有效答案、来源依据、反馈和参考答案。JSON 保留答案版本历史；正式完成进度按有效步骤计算，而不是按 turns 数量计算。正式成长统计排除测试会话，并分别统计本地完成和 AI 评分覆盖。

## 界面边界

宽屏显示原文和训练卡；窄屏提供“原文 / 训练”切换，并恢复两个区域各自的阅读位置。长说明默认收起，当前主任务保持清楚。保存中、已保存和保存失败必须可辨认；失败时提供重试，不显示虚假的已保存状态。
